    数字逻辑：内存与IP核

    实验目标

    • 理解内存的基本概念与工作原理
    • 掌握用 Verilog 设计单端口 RAM
    • 学会在 Vivado 中使用 Block RAM IP核设计高效内存

    1. 内存基础概念

    特性 RAM（随机存取存储器） ROM（只读存储器）
    全称 Random Access Memory Read-Only Memory
    读写 可读可写 只读

    在 FPGA 中，我们主要使用 Block RAM（块式 RAM），它是 FPGA 内部的一种硬件资源，具有高带宽和低延迟的特点。

    如下图所示，内存由addr进行访问

    假设一个内存由K bit的地址线访问，每个存储单元位宽为N bit，则该内存容量为 N * 2^K bit。

    2 Verilog实现：单端口 RAM

    一个单端口 RAM 在同一时刻只能进行一次操作（读或写），但成本最低。

    2.1 异步读：

    读数据为组合逻辑，可立即读出

    module ram_single_port #(
    parameter ADDR_WIDTH = 10,  // 地址宽度（2^10 = 1024个单元）
    parameter DATA_WIDTH = 8   // 数据宽度（8位）
) (
    input  clk,
    input  we,                      // 写使能（高电平写入）
    input  [ADDR_WIDTH-1:0] addr,   // 地址
    input  [DATA_WIDTH-1:0] din,    // 数据输入
    output [DATA_WIDTH-1:0] dout    // 数据输出
);

    // 声明存储体：1024×8 的 RAM
    reg [DATA_WIDTH-1:0] mem [0:(1<<ADDR_WIDTH)-1];

    // 同步读写
    always @(posedge clk) begin
        if (we)
            mem[addr] <= din;  // 写入
    end

    // 异步读出（组合逻辑）
    assign dout = mem[addr];

endmodule

    关键点：

    • reg [7:0] mem [0:1023]：定义 1024 个 8 位的存储单元
    • mem[addr] <= din：写入操作在时钟上升沿执行
    • dout = mem[addr]：读出是组合逻辑，无延迟

    2.2 同步读

    读数据为时序逻辑，（延迟 1 拍），即读逻辑在always语句块中，使用非阻塞赋值：

    module ram_sync_read #(
    parameter ADDR_WIDTH = 10,
    parameter DATA_WIDTH = 8
) (
    input  clk,
    input  we,
    input  [ADDR_WIDTH-1:0] addr,
    input  [DATA_WIDTH-1:0] din,
    output reg [DATA_WIDTH-1:0] dout
);

    reg [DATA_WIDTH-1:0] mem [0:(1<<ADDR_WIDTH)-1];

    always @(posedge clk) begin
        if (we)
            mem[addr] <= din;
        else
            dout <= mem[addr];  // 同步读出
    end

endmodule

    关键点：

    • dout <= mem[addr]：读出是时序逻辑，在时钟上升沿同步读到数据
    • 优点：与时序设计更融合，便于流水线操作。

    2.3 初始化 RAM（用于 ROM 功能）

    有时我们希望 RAM 在上电时已经包含数据（如程序代码、查找表）：

    module ram_with_init #(
    parameter DATA_WIDTH = 10,
    parameter ADDR_WIDTH = 8
) (
    input  clk,
    input  we,
    input  [ADDR_WIDTH-1:0] addr,
    input  [DATA_WIDTH-1:0] din,
    output [DATA_WIDTH-1:0] dout
);

    reg [DATA_WIDTH-1:0] mem [0:(1<<ADDR_WIDTH)-1];

    // 从文件初始化
    initial begin
        $readmemh("mem_init.hex", mem);  // 从 .hex 文件读取数据
    end

    always @(posedge clk) begin
        if (we)
            mem[addr] <= din;
    end

    assign dout = mem[addr];

endmodule

    .hex 文件格式（十六进制）：

    3C  // 地址 0
10  // 地址 1
A5  // 地址 2
FF  // 地址 3
...

    3. Vivado Block RAM IP核

    3.1 为什么用 IP核？

    用 Verilog 手写的 RAM 在综合时可能不会最优地利用 FPGA 的硬件 Block RAM 资源。Vivado 提供了 Block RAM IP核，它能： - 自动优化，充分利用 FPGA 的硬件 Block RAM - 提供多种配置选项（宽度、深度、初始值等） - 比手写 RTL 性能更好、资源占用更少

    3.2 创建 Block RAM IP核

    步骤 1：打开 IP 目录

    在 Vivado 中：Project Manager → IP Catalog

    步骤 2：搜索 Block RAM

    在搜索框输入 Block Memory Generator，选择 Xilinx 官方 IP。

    步骤 3：配置参数

    打开 IP Customization 对话框，按照图片内容进行设置

    步骤 4：生成 IP 核

    1. 点击 OK 完成配置
    2. Vivado 生成 RTL 文件和 simulation 文件
    3. IP核会出现在项目的 ip_repo 中

    3.3 Block RAM IP的接口

    生成后的 Block RAM IP 核有以下端口（以单端口为例）：

    module blk_mem_gen_0 (
    input  clka,           // 时钟
    input  wea,            // 写使能（[0] 对应字节使能）
    input  [9:0] addra,    // 地址
    input  [7:0] dina,     // 数据输入
    output [7:0] douta     // 数据输出
);

    在设计中调用 Block RAM IP

    module ram_controller (
    input  clk,
    input  we,
    input  [9:0] addr,
    input  [7:0] din,
    output [7:0] dout
);

    // 调用生成的 IP 核
    blk_mem_gen_0 ram_inst (
        .clka(clk),
        .wea(we),  
        .addra(addr),
        .dina(din),
        .douta(dout)
    );

endmodule

    4. 实践：简单 RAM 仿真

    4.1 需求

    设计并验证一个基础 RAM 模块，功能如下： - 容量：1024 × 8 bits（10 位地址，8 位数据） - 操作：同步读、同步写 - 测试：先写入若干数据到不同地址，再读出验证

    4.2 RAM 模块实现

    设计说明：

    • addr 为 10 位，可寻址 2^10 = 1024 个单元
    • we 为高时执行写入，为低时执行读出
    • 读写均在时钟上升沿进行，读输出为稳定读入地址之后的上升沿
    • 可使用verilog，或IP核实现。

    4.3 仿真测试

    testbench 流程：

    1. 写入阶段：将测试数据写入到不同地址
    2. 读出阶段：从之前写入过的地址读出数据，验证是否正确

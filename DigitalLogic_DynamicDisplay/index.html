    数字逻辑：跑马灯与数码管动态显示

    实验目标

    • 学会用移位寄存器实现跑马灯效果
    • 理解多位数码管动态扫描显示的原理
    • 在 EGO1 开发板上实现 8 位 LED 跑马灯和 4 位数码管显示

    1. Demo1：8位LED跑马灯

    1.1 设计目标

    在 EGO1 开发板的 8 个 LED（LED0-LED7）上实现跑马灯效果：

    • 同一时刻只有 1 个 LED 亮
    • 亮灯位置每 1 秒移动一次
    • 从左（LED7）往右（LED0）依次移动
    • 到达最右后回到最左，循环往复

    1.2 设计思路

    跑马灯的本质是 分频器 + 循环移位：

    1. 用计数器将 100MHz 时钟分频到 1Hz
    2. 每当计数满 1 秒时，将 LED 图案循环右移一位

    循环右移可以用 Verilog 拼接运算符实现：

    led <= {led[0], led[7:1]};  // 循环右移

    这行代码做了什么？

    • led[7:1]：取高 7 位
    • led[0]：取最低位
    • {led[0], led[7:1]}：把最低位拼到最高位前面 → 整体右移一位

    初始状态 led = 8'b1000_0000（只有 LED7 亮），移位过程如下：

    8'b1000_0000  →  8'b0100_0000  →  8'b0010_0000  →  ...  →  8'b0000_0001  →  8'b1000_0000
   LED7亮          LED6亮           LED5亮                     LED0亮          回到LED7

    1.3 关于初始化

    在 Xilinx FPGA 上，寄存器在上电时会自动初始化为代码中指定的初始值。因此我们可以用 initial 语句设置初始状态，而不需要复位信号：

    reg [31:0] cnt = 0;          // 计数器初始为 0
initial led = 8'b1000_0000;  // LED 初始状态：最左边亮

    注意：initial 语句在 Xilinx FPGA 综合时有效，但并非所有 FPGA 厂商都支持。本课程使用 EGO1 开发板（Xilinx Artix-7），可以放心使用。

    1.4 参数化分频系数

    这里用 parameter 设定分频系数，方便在仿真和上板时切换：

    module running_led #(
    parameter MAX_COUNT = 100_000_000  // 默认：100MHz / 1亿 = 1Hz
)(
    input            clk,
    output reg [7:0] led
);

    仿真时传入较小的值加速：

    running_led #(.MAX_COUNT(10)) uut ( ... );  // 仿真用，10 个周期移一位

    上板时使用默认值（1 亿），无需修改设计代码。

    1.5 完整设计代码

    module running_led #(
    parameter MAX_COUNT = 100_000_000
)(
    input            clk,
    output reg [7:0] led
);

    reg [31:0] cnt = 0;

    initial led = 8'b1000_0000;

    always @(posedge clk) begin
        if (cnt == MAX_COUNT - 1) begin
            cnt <= 0;
            led <= {led[0], led[7:1]};
        end else begin
            cnt <= cnt + 1;
        end
    end

endmodule

    代码要点：

    • 计数器 cnt 从 0 计到 MAX_COUNT - 1，计满时清零并移位
    • 移位和计数在同一个 always 块中完成，逻辑清晰

    1.6 Testbench

    `timescale 1ns/1ps

module tb_running_led();

    2. 数码管动态扫描原理

    2.1 为什么需要动态扫描？

    EGO1 左右两组各自分别共用同一套段选信号。这意味着在同一时刻，左右两组数码管各自只能显示同一个字形。

    那如何让它们显示不同内容？答案就是动态扫描——分时复用。

    2.2 动态扫描原理

    1. 在极短的时间内，只点亮 1 个数码管，显示它对应的数字
    2. 然后切换到下一个数码管
    3. 4 个数码管快速交替显示
    4. 切换足够快（>200Hz/位），人眼的暂留效应使我们感觉"同时"在亮

    时序示意：

    时间 →
BIT1: ████                    ████                    ████
BIT2:      ████                    ████                    ████
BIT3:           ████                    ████                    ████
BIT4:                ████                    ████                    
段码:  D0   D1   D2   D3   D0   D1   D2   D3   ...

    2.3 实现架构

    下图为通用框架图，通过分频和计数产生慢速显示时钟（DISP_CLK），产生片选译码信号B1B0，用于决定当前时刻要点亮几号数码管上，以及要在该数码管上显示什么图案。

    2.4 分频器

    可以参考下面这些参数：

    parameter PERIOD = 200_000;   // 500Hz，显示稳定
// parameter PERIOD = 250_000; // 400Hz，显示稳定
// parameter PERIOD = 5_000_000; // 20Hz，能明显看到一位一位轮流亮
// parameter PERIOD = 2_500_000; // 40Hz，会有明显闪烁
// parameter PERIOD = 1_000_000; // 100Hz，轻微闪烁

    reg [31:0] div_cnt;
reg        scan_clk;

always @(posedge clk or negedge rst_n) begin
    if (!rst_n) begin
        div_cnt  <= 32'd0;
        scan_clk <= 1'b0;
    end else if (div_cnt == (PERIOD >> 1) - 1) begin
        div_cnt  <= 32'd0;
        scan_clk <= ~scan_clk;
    end else begin
        div_cnt  <= div_cnt + 1'd1;
    end
end

    代码要点：

    • PERIOD 表示 scan_clk 的周期对应多少个系统时钟周期
    • 当计数到半个周期时，把 scan_clk 翻转一次
    • 最终得到稳定的低频扫描时钟

    2.5 扫描计数器

    reg [1:0] scan_cnt;

always @(posedge scan_clk or negedge rst_n) begin
    if (!rst_n)
        scan_cnt <= 2'd0;
    else if (scan_cnt == 2'd3)
        scan_cnt <= 2'd0;
    else
        scan_cnt <= scan_cnt + 1'd1;
end

    这个计数器的含义很直接：

    • 0：扫描第 1 位
    • 1：扫描第 2 位
    • 2：扫描第 3 位
    • 3：扫描第 4 位

    2.6 片选信号

    使用 one-hot 编码——同一时刻只选通一个数码管（此顺序仅作举例）：

    scan_cnt 选通数码管
    2'd0 BIT1（左1）
    2'd1 BIT2
    2'd2 BIT3
    2'd3 BIT4（左4）

    4. 实验练习

    补全Demo2的代码（填空）、并在代码文件开头添加以下内容（建议新建一个文件），将display设置为“Top”，添加xdc文件，绑定引脚，在 EGO1 开发板4个数码上管显示 1234 。

    module display (
    input        clk,
    input        rst_n,
    output [7:0] seg, //段选信号
    output [3:0] an //片选信号
);
    dynamic_display u_disp (
        .clk(clk), .rst_n(rst_n),
        .digit0(4'd1), .digit1(4'd2),
        .digit2(4'd3), .digit3(4'd4),
        .seg(seg), .an(an)
    );
endmodule

    附录：常见问题

    • 问：数码管闪烁或有部分不亮？ 答：检查片选信号 an 是否为 one-hot 编码（每次只有一位为 1），以及 `scan_cnt 的取值是否涵盖了所有 4 位。

    • 问：数码管显示乱码？ 答：检查 seg 的位序 {a,b,c,d,e,f,g,dp} 是否与引脚约束中 seg[7]~seg[0] 的对应关系一致。对照 2.7 节的字形图逐位确认。

    • 问：只有一个数码管亮？ 答：检查 scan_cnt 是否在正常计数（可以在仿真波形中观察），以及片选的引脚约束是否正确。

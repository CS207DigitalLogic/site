    数字逻辑：按键消抖与边沿检测

    实验目标

    • 理解机械按键的抖动现象及其对数字电路的影响
    • 掌握边沿检测原理（从电平信号提取单周期脉冲）
    • 掌握两种基于计数器的按键消抖方法：电平型消抖与脉冲型消抖
    • 理解两种方法的区别与适用场景
    • 实现"按一次按键，只响应一次"的正确行为

    说明：EGO1 开发板右侧的 5 个通用按键默认低电平，按下为高电平（高电平有效）。本文所有代码和波形图都按高电平有效绘制。本实验中的每个设计都在一个模块内完成。

    1. 按键抖动问题

    1.1 机械按键的物理特性

    开发板上的按键是机械开关。按下或释放按键时，金属触点之间会发生多次弹跳，导致信号在 0 和 1 之间快速跳变，持续约 5~20ms。

    1.2 抖动的危害

    如果直接使用未消抖的按键信号驱动计数器：

    • 你期望"按一次加 1"
    • 实际结果可能"按一次加了 3~10 次"
    • 因为每次弹跳都会产生一个上升沿，触发计数

    本实验将分两步解决"按一次只响应一次"的问题：

    1. 边沿检测：解决"按住按键时一直响应"的问题（第 2 节）
    2. 按键消抖：解决"按一次响应好几次"的问题（第 4、5 节）

    2. 边沿检测：从电平到单脉冲

    2.1 为什么不能直接用电平做使能？

    假设按键信号已经是干净的电平（不考虑抖动），我们想实现"按一次计数器加 1"。最直观的写法是：

    always @(posedge clk) begin
    if (btn_level)
        cnt <= cnt + 1'b1;
end

    问题在于：btn_level 是一个电平信号。按一次按键大约持续 100ms~1s，在 100MHz 时钟下就是几千万个时钟周期。按住期间每个时钟沿计数器都会加 1，结果是按一次加了几千万。

    我们需要的是：只在按下的那一个时钟周期产生高电平，这就是边沿检测要做的事。

    2.2 不能用 posedge 检测普通信号

    初学者常见的一个错误，是直接把普通信号写进 always 块的边沿触发列表里：

    错误写法：

    always @(posedge btn_level) begin
    cnt <= cnt + 1'b1;
end
// 这里的 btn_level 只是普通信号，并不是时钟或复位

    不能这么写的原因是：芯片内部有专门的全局时钟布线网络，用来保证时钟信号延迟低、到达各触发器的时间一致。如果对普通信号使用 posedge 或 negedge，综合工具会把这个普通信号当作时钟处理。普通连线达不到时钟网络的要求，容易引入毛刺和时序错误，甚至导致工程无法综合下板。

    正确写法：

    always @(posedge clk) begin
    if (pos_edge)
        cnt <= cnt + 1'b1;
end

    这里的 pos_edge 是一个与时钟 clk 同步的信号。当输入信号出现上升沿时，pos_edge 变成 1，并且只持续一个时钟周期。这样既能检测到跳变，电路又始终工作在同一个时钟下。

    2.3 边沿检测原理

    使用一个寄存器保存上一个时钟周期的信号值，通过比较当前值和上一个周期的值来判断边沿：

    当前值 sig_in ： 0 0 0 1 1 1 1 0 0
上一拍 sig_d  ： 0 0 0 0 1 1 1 1 0
上升沿 pos_edge： 0 0 0 1 0 0 0 0 0   （当前=1 且 上一拍=0）
下降沿 neg_edge： 0 0 0 0 0 0 0 1 0   （当前=0 且 上一拍=1）

    对应的时序波形如下：

    • sig_d 比 sig_in 晚一个时钟周期
    • 在 sig_in 已经变高而 sig_d 还没变高的这一个周期里，pos_edge = 1
    • 同理，在 sig_in 已经变低而 sig_d 还没变低的这一个周期里，neg_edge = 1

    2.4 边沿检测代码

    module edge_detect (
    input      clk,
    input      rst_n,
    input      sig_in,       // 输入信号
    output     pos_edge,     // 上升沿脉冲（单周期）
    output     neg_edge      // 下降沿脉冲（单周期）
);
    reg sig_d;  // 延迟一拍的信号

    always @(posedge clk or negedge rst_n) begin
        if (!rst_n)
            sig_d <= 1'b0;
        else
            sig_d <= sig_in;
    end

    assign pos_edge = sig_in & ~sig_d;  // 当前高，上一拍低 → 上升沿
    assign neg_edge = ~sig_in & sig_d;  // 当前低，上一拍高 → 下降沿
endmodule

    边沿检测的核心只有三行：一个寄存一拍的 always 块，加两条 assign。后面各节会把这三行直接写进需要它的模块里。

    3. 观察抖动：边沿检测直接接原始按键

    3.1 实验

    先不做消抖，在一个模块里完成"边沿检测 + 计数器"，计数值用 8 个 LED 以二进制显示：

    module btn_raw_cnt (
    input            clk,
    input            rst_n,
    input            btn_in,     // 原始按键，按下为高
    output reg [7:0] led         // 计数值，二进制显示
);
    // 边沿检测
    reg  btn_d;
    wire btn_pos;

    always @(posedge clk or negedge rst_n) begin
        if (!rst_n)
            btn_d <= 1'b0;
        else
            btn_d <= btn_in;
    end

    assign btn_pos = btn_in & ~btn_d;

    // 计数器：每检测到一个上升沿加 1
    always @(posedge clk or negedge rst_n) begin
        if (!rst_n)
            led <= 8'd0;
        else if (btn_pos)
            led <= led + 1'b1;
    end
endmodule

    上板后按一次按键，观察 LED 显示的计数值。

    3.2 现象与分析

    按一次按键，计数值经常增加好几个。原因如下图：抖动期间每次从 0 变到 1 都是一个上升沿，边沿检测会把每一个上升沿都检测出来。

    提示：这一步用计数器观察，而不用 LED 翻转。如果抖动产生了偶数个上升沿，LED 翻转偶数次后状态不变，容易误以为代码有错。

    结论：边沿检测只能把电平变成脉冲，无法区分真正的按下和抖动。必须先消抖。

    4. 消抖方法一：电平型消抖 + 边沿检测

    4.1 原理：采样等稳

    输入发生变化后，输出不立即改变，而是等输入保持新值达到 20ms 后才更新。具体步骤：

    1. 每个时钟周期比较按键输入 btn_in 和当前输出 btn_level
    2. 两者相同：说明没有变化，计数器清零
    3. 两者不同：说明按键可能变了，计数器开始累加
    4. 计数过程中如果按键又变回原值（两者又相同），说明还在抖动，计数器清零重新开始
    5. 计数器计满 20ms：说明新电平已经稳定，更新 btn_level

    这种方法对按下和释放都会消抖，输出是一个干净的、比原始信号延迟约 20ms 的方波。由于输出是电平，还需要再做一次边沿检测，才能得到按下或释放时的单周期脉冲 btn_pos、btn_neg。

    4.2 延时参数计算

    • 消抖时间目标：约 20ms
    • 系统时钟：100MHz → 1 个周期 = 10ns
    • 20ms = 20,000,000 ns
    • 需要计数次数 = 20,000,000 / 10 = 2,000,000

    所以 CNT_MAX = 2_000_000。

    计数器位宽：计数范围是 0 ~ 1,999,999，而 2²¹ = 2,097,152 > 2,000,000，所以位宽取 21 位，即 reg [20:0] cnt。

    4.3 代码

    消抖和边沿检测写在同一个模块里：

    module btn_debounce #(
    parameter CNT_MAX = 21'd2_000_000      // 20ms @ 100MHz
)(
    input      clk,
    input      rst_n,
    input      btn_in,                     // 按键输入，按下为高
    output reg btn_level,                  // 消抖后的干净电平
    output     btn_pos,                    // 按下时的单周期脉冲
    output     btn_neg                     // 释放时的单周期脉冲
);
    // ---------------- 第一部分：电平型消抖 ----------------
    // 输入与当前输出不同，并持续 20ms，才更新输出
    reg [20:0] cnt;                        // 2^21 = 2,097,152 > 2,000,000
    always @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            cnt       <= 21'd0;
            btn_level <= 1'b0;
        end
        else if (btn_in == btn_level)      // 没有变化（或抖动变回原值）：清零
            cnt <= 21'd0;
        else if (cnt == CNT_MAX - 1) begin // 新电平稳定满 20ms：更新输出
            btn_level <= btn_in;
            cnt       <= 21'd0;
        end
        else                               // 有变化但还没稳定够 20ms：继续计数
            cnt <= cnt + 1'b1;
    end

    // ---------------- 第二部分：边沿检测 ----------------
    reg btn_level_d;                       // btn_level 延迟一拍
    always @(posedge clk or negedge rst_n) begin
        if (!rst_n)
            btn_level_d <= 1'b0;
        else
            btn_level_d <= btn_level;
    end

    assign btn_pos = btn_level & ~btn_level_d;   // 上升沿：按下
    assign btn_neg = ~btn_level & btn_level_d;   // 下降沿：释放
endmodule

    信号处理流程：

    btn_in(有抖动) → [消抖] → btn_level(干净电平) → [边沿检测] → btn_pos / btn_neg(单脉冲)

    4.4 时序分析

    工作流程：

    1. 按键按下 → btn_in 开始抖动
    2. btn_in 与 btn_level 不同时 cnt 累加；抖动变回原值时两者相同，cnt 清零
    3. 抖动结束后 btn_in 稳定为 1，cnt 持续累加到 N-1
    4. 下一个时钟沿 btn_level 变为 1，cnt 清零；此时边沿检测输出一个周期的 btn_pos
    5. 释放时过程与按下对称，最终 btn_level 变回 0，边沿检测输出一个周期的 btn_neg

    图中 N = CNT_MAX = 2,000,000；"3 ~ N-2" 表示中间省略了约两百万个时钟周期。

    4.5 仿真技巧

    如果直接用 CNT_MAX = 2_000_000 仿真，一次按键就要仿真几百万个时钟周期，速度非常慢。仿真时可以临时把参数的默认值改小：

    parameter CNT_MAX = 21'd10             // 仿真用：只需稳定 10 个时钟周期

    相应地，testbench 中模拟的抖动脉冲宽度也要小于 10 个时钟周期。上板前记得改回 21'd2_000_000。

    5. 消抖方法二：脉冲型消抖

    5.1 思路

    很多场合只需要知道"按键被按下了一次"。这时可以直接在消抖的计数过程中产生脉冲，不需要单独的边沿检测：

    1. 按键为高（按下）时计数器累加，为低时清零
    2. 抖动期间按键会多次变回低电平，计数器多次清零
    3. 按键稳定为高并持续 20ms，计数器计到 N-1
    4. 在计数器第一次到达 N-1 时输出一个时钟周期的脉冲
    5. 之后计数器保持在 N-1 不变，所以按住期间不会再产生脉冲
    6. 松开后计数器清零，等待下一次按下

    注意：这种方法只在按下时输出脉冲，释放时没有输出。

    5.2 代码

    module btn_debounce_pulse #(
    parameter CNT_MAX = 21'd2_000_000      // 20ms @ 100MHz
)(
    input      clk,
    input      rst_n,
    input      btn_in,                     // 按键输入，按下为高
    output reg btn_pulse                   // 每次按下输出 1 个时钟周期的脉冲
);
    // 按住时计数，计到 N-1 后保持；松开或抖动回低则清零
    reg [20:0] cnt;
    always @(posedge clk or negedge rst_n) begin
        if (!rst_n)
            cnt <= 21'd0;
        else if (btn_in == 1'b0)
            cnt <= 21'd0;
        else if (cnt == CNT_MAX - 1)
            cnt <= cnt;                    // 保持不变，防止重复触发
        else
            cnt <= cnt + 1'b1;
    end

    // 计数器只会被 CNT_MAX-2 触发一次，因此只输出一个周期的脉冲
    always @(posedge clk or negedge rst_n) begin
        if (!rst_n)
            btn_pulse <= 1'b0;
        else if (cnt == CNT_MAX - 2)
            // cnt 为 N-2 时，下一个时钟沿 cnt 变为 N-1，btn_pulse 同时拉高
            btn_pulse <= 1'b1;
        else
            btn_pulse <= 1'b0;
    end
endmodule

    5.3 时序分析

    • 抖动期间 btn_in 每次回到 0，cnt 都清零
    • 稳定按下后 cnt 累加到 N-1 并保持（图中 "N-1 (hold)"）
    • btn_pulse 在 cnt 第一次等于 N-1 的那个周期为高
    • 释放时 cnt 清零，释放抖动只会让 cnt 在 0、1 之间变化，不会产生脉冲

    5.4 思考题

    如果在方法二的模块里，再对 btn_pulse 做一次边沿检测（用寄存器 btn_pulse_d 保存上一拍的值，令 pos = btn_pulse & ~btn_pulse_d），得到的 pos 是什么样的？

    点击查看答案 - btn_pulse 为高的那一拍，btn_pulse_d 还是 0，所以 pos = 1；下一拍 btn_pulse 已经变回 0，pos = 0。因此 pos 与 btn_pulse 完全相同，这次边沿检测是多余的。 结论：脉冲型消抖的输出已经是单周期脉冲，不需要再做边沿检测；电平型消抖的输出是电平，必须再做边沿检测。

    6. 两种方法对比

    方法一：电平型消抖 + 边沿检测 方法二：脉冲型消抖
    消抖部分的输出 干净的方波（电平） 单周期脉冲
    是否需要边沿检测 需要 不需要
    消抖范围 按下、释放都消抖 只针对按下
    能否检测释放 能（btn_neg） 不能
    能否实现长按检测 能（对 btn_level 计时） 需要修改代码
    代码组成 消抖逻辑 + 边沿检测逻辑 只有消抖逻辑
    适用场景 通用，便于扩展 只需"按一次做一次"

    两种方法都是工程中常见的写法。方法一功能更完整，推荐作为默认写法；方法二代码更少，适合只需要响应按下的简单场景。

    7. 实验练习

    要求使用 EGO1 开发板右侧 5 个按键中的一个上板测试。所有功能都在一个模块内完成。

    练习 1（基础）：按一次，LED 翻转

    在方法一的 btn_debounce 模块中增加一个输出 led，利用 btn_pos 实现：每按一次按键，LED 翻转一次状态。

    附录：常见问题

    • 问：消抖后按键还是跳数？ 答：检查 CNT_MAX 是否够大。20ms（2_000_000 @ 100MHz）是推荐值。如果值太小，抖动还没结束输出就更新了。另外检查上板时是否忘记把仿真用的 CNT_MAX 改回原值。

    • 问：按键完全没反应？ 答：检查按键引脚约束是否正确。EGO1 的 5 个通用按键是高电平有效（按下为 1）；如果你使用的是其他开发板且按键为低电平有效，需要先对输入取反。

    • 问：仿真了很长时间还是看不到输出变化？ 答：仿真时把 CNT_MAX 临时改小（如 10），见 4.5 节。

    • 问：为什么修改了 CNT_MAX 后计数异常？ 答：计数器位宽固定为 21 位，最大可计到 2,097,151。如果将 CNT_MAX 改得比这个值更大（例如更高的时钟频率或更长的消抖时间），需要同时加大 cnt 的位宽。

    数字逻辑：按键驱动计数器显示

    实验目标

    • 掌握多模块互连的设计方法（顶层模块编写）
    • 练习将独立模块组装成一个完整系统
    • 理解模块接口设计与信号命名规范
    • 完成"单位十六进制计数显示器"：按一次按键，数码管增加一个数值（0-F-0循环）

    1. 模块化设计回顾

    1.1 需要的模块

    在前几周中，我们分别实现了以下独立模块：

    模块 功能
    counter_mod 模N计数器（带使能和进位）
    dynamic_display 7段数码管显示驱动
    btn_debounce 按键消抖
    edge_detect 边沿检测

    1.2 顶层模块框图

         ┌──────────────────────── 顶层模块 ──────────────────────┐
     │                                                       │
     │  ┌──────────┐  pulse   ┌──────────┐  count            │
clk─→│  │ btn_deb  │ ────────→│ counter  │────────┐          │
btn─→│  │+ edge_de │          │ MOD(16)  │        │          │
     │  └──────────┘          └──────────┘        │          │
     │                                            │          │
     │                                     digit0 │          │ 
     │                      ┌─────────────────┐←──│          │
     │                      │ dynamic_display │   │  seg ──→ seg
     │   digit1,2,3 = 0 ───→│   (4位)         │───┤─→ an  ──→ an
     │                      └─────────────────┘              │
     │                                                       │
     └───────────────────────────────────────────────────────┘

    2. 项目需求：单位数码管计数器

    2.1 功能描述

    设计单个digit的十六进制计数显示器： - 使用 1个数码管（仅显示单个十六进制数字） - 显示范围：0 → 1 → 2 → ... → 9 → A → B → ... → F → 0（循环） - 按下按键一次，数字 +1 - 按键消抖确保每次按下产生一个脉冲 - 按下复位键，数字清零

    2.2 模块分解

    子模块 实例数 功能
    counter_mod #(.MOD(16)) 1 模16计数器（0-9, A-F）
    dynamic_display 1 数码管驱动（只使用1位）
    btn_debounce 1 按键消抖
    edge_detect 1 按键边沿检测

    2.3 设计要点

    按键 → 消抖 → 边沿检测 → 计数器enable → 计数器输出 → 数码管显示
(btn)  (clean) (pulse)    (en)         (count)      (seg)

    3. 顶层模块编写

    3.1 端口声明

    module hex_counter_top (
    input        clk,       // 100MHz 系统时钟
    input        btn,       // 按键 （Ego1：R15）
    output [7:0] seg,       // 数码管段选
    output [3:0] an         // 数码管片选
);

    3.2 完整顶层模块

    module hex_counter_top (
    input        clk,       // 100MHz 系统时钟
    input        btn_inc,   // 增加按键
    output [7:0] seg,       // 数码管段选
    output [3:0] an         // 数码管片选
);

    // 内部信号
    wire btn_clean; //消抖后的按键信号
    wire btn_pulse; //按键脉冲
    wire [3:0] count;

    // 按键消抖
    btn_debounce u_deb (
        .clk(clk), .rst_n(1'b1),
        .btn_in(btn), .btn_out(btn_clean)
    );

    // 边沿检测
    edge_detect u_edge (
        .clk(clk), .rst_n(1'b1),
        .sig_in(btn_clean),
        .pos_edge(btn_pulse), .neg_edge()
    );

    // 计数器
    counter_mod ...

    // 数码管显示
    dynamic_display ...

endmodule

    3.3 关键连线要点

    信号 来源 目标 说明
    btn → btn_clean 按键 → 消抖模块 去抖后信号 消除按键抖动
    btn_clean → btn_pulse 消抖 → 边沿检测 脉冲信号 上升沿触发
    btn_pulse → counter_mod.en 脉冲 → 计数器 计数使能 每个脉冲 +1
    count → digit[?] 计数器 → 显示 个位值 十六进制显示
    digit[?] 0 显示 其他位不显示
    seg, an 显示驱动 外部数码管 段选、片选信号

    4. 实验练习

    步骤1：准备子模块

    将以下模块代码复制到工程中： - counter_mod.v - 注意参数设置 - dynamic_display.v - btn_debounce.v - edge_detect.v

    步骤2：编写顶层模块

    参考第3节，编写 hex_counter_top.v： - 实例化按键消抖、边沿检测、计数器、显示驱动四个模块 - 关键：正确连接 btn_pulse 到 counter_mod.en - 设置 counter_mod.MOD（0-15 计数） - 仅将 count 输出连接到 digit0，其他 digit 为 0

    步骤3：仿真验证 (optional)

    • 验证按键触发一次 +1（注意消抖参数，需适配仿真时间）
    • 验证十六进制显示：0→1→...→9→A→B→C→D→E→F→0

    步骤4：引脚约束与上板

    • 使用数码管约束
    • 添加按键约束（选择一个按键作为增加键）
    • 仅激活数码管的最右位（an[0]=0，其他=1）

    5. 思考题

    Q1：如何只改动顶层文件的连线（不修改 counter_mod），让计数变成 0-9（十进制）而不是 0-F？

    • 参数化设置

    Q3：如果要显示两位十六进制数（0x00-0xFF），应该如何修改？

    解决思路： - 添加两个计数器级联：个位 和十位 - 个位 enable = btn_pulse - 十位 enable = 个位的进位信号 - 将计数值分别连接到数码管两个digit

    Q4：为什么使用 dynamic_display 模块而不是直接驱动？

    分析： - dynamic_display 已经封装好了 7 段数码管驱动逻辑和到十六进制数字的映射 - 模块化提高了代码的可复用性和可读性 - 支持多位数码管的动态扫描显示

    数字逻辑：UART 串口通信与仿真调试

    实验目标

    • 理解 UART 异步串行通信的基本原理与 8N1 数据帧格式
    • 掌握波特率分频参数的计算方法，以及 Verilog 模块参数 parameter 的使用
    • 使用 Verilog 实现 UART 发送模块和接收模块
    • 完成 EGO1 与电脑串口调试助手之间的双向通信
    • 掌握利用 Vivado 波形窗口和内部信号定位问题的基本方法

    1. UART 基础

    1.1 什么是 UART？

    UART（Universal Asynchronous Receiver/Transmitter，通用异步收发器）是一种常用的串行通信方式。

    与同步通信不同，UART 不传输时钟信号。发送端和接收端必须提前约定相同的波特率和帧格式，再按照约定的时间间隔发送、采样数据。

    UART 全双工通信通常只需要 3 根线：

    信号 方向 功能
    TX 发送端输出 串行发送数据
    RX 接收端输入 串行接收数据
    GND 双方共地 提供共同的电平参考

    连接两个设备时应当交叉连接数据线：一方的 TX 连接另一方的 RX，同时保证两端共地。

    1.2 UART 数据帧

    UART 数据线在空闲状态保持高电平。一次传输由起始位、数据位、可选校验位和停止位组成。

    本实验统一使用 115200-8-N-1：

    配置项 本实验设置 说明
    波特率 115200 每秒传输 115200 个符号
    数据位 8 每帧传输 1 字节（LSB起传）
    校验位 None 不使用奇偶校验
    停止位 1 使用 1 位高电平停止位

    一帧数据的传输顺序如下：

    1. 空闲状态：1
    2. 起始位：0
    3. 8 位数据：从最低位 LSB 到最高位 MSB
    4. 停止位：1

    例如发送 8'h53，其二进制为 0101_0011。UART 数据位按照 LSB first 传输，因此线上数据位依次为 1、1、0、0、1、0、1、0。

    1.3 波特率分频

    FPGA 使用 100 MHz 系统时钟，而 UART 每一位需要保持一个波特周期。代码中用分频计数器产生采样或移位时刻：

    localparam BAUD_DIV = CLK_FREQ / BAUD_RATE;

    本实验中：

    BAUD_DIV = 100_000_000 / 115_200 = 868（整数除法）

    因此每个 UART 位保持约 868 个系统时钟周期。实际波特率约为 100_000_000 / 868 = 115207.37，与目标值的误差约为 0.0064%，可以正常通信。

    1.4 使用参数提高模块复用性

    parameter 是编译期常量。将时钟频率和波特率写成参数，同一份 UART 模块可以复用于不同的时钟和通信速率：

    module uart_tx #(
    parameter CLK_FREQ  = 100_000_000,
    parameter BAUD_RATE = 115200
)(
    // 端口定义
);

    在顶层模块实例化时可以覆盖参数：

    uart_tx #(
    .CLK_FREQ(100_000_000),
    .BAUD_RATE(115200)
) uart_tx_inst (
    // 端口连接
);

    2. UART Demo 功能与结构

    2.1 实验功能

    将 UART 电路下载到 EGO1 后，实现以下双向通信：

    • FPGA → 电脑：用 8 位拨码开关设置一个字节，按下发送按键后，通过 uart_tx 发送到电脑，并在串口调试助手的接收窗口显示
    • 电脑 → FPGA：在串口调试助手中发送一个字节，FPGA 通过 uart_rx 接收，并用 8 个 LED 显示该字节

    2.2 顶层端口

    module top(
    input  wire       clk,             // 100 MHz 系统时钟
    input  wire [7:0] key,             // 8 位拨码开关
    input  wire       uart_rx,         // 电脑发送到 FPGA 的数据
    output wire       uart_tx,         // FPGA 发送到电脑的数据
    output reg  [7:0] led,             // 显示接收到的数据
    input  wire       uart_tx_rst_n,   // UART TX 复位/使能，低有效
    input  wire       uart_rx_rst_n,   // UART RX 复位/使能，低有效
    input  wire       send_one,        // 低有效发送按键
    output wire       uart_tx_work,    // TX 工作状态指示
    output wire       uart_rx_work     // RX 工作状态指示
);
    顶层端口 板上资源 功能
    key[7:0] 8 个拨码开关 设置待发送字节
    send_one 按键 按下一次，触发一次发送
    led[7:0] 8 个 LED 显示电脑发来的字节
    uart_tx_rst_n 拨码开关 置 1 时允许发送模块工作
    uart_rx_rst_n 拨码开关 置 1 时允许接收模块工作
    uart_tx_work LED 显示发送模块是否已解除复位
    uart_rx_work LED 显示接收模块是否已解除复位
    uart_tx / uart_rx 板载 UART 与电脑进行串行通信

    2.3 模块划分

    系统可分为 4 个主要部分：

    1. uart_rx：同步并采样 uart_rx，输出接收到的字节和完成脉冲
    2. LED 锁存：检测 rx_done，把 rx_data 保存到 led
    3. 按键边沿检测：把一次按键动作转换为单个时钟周期的 send_flag
    4. uart_tx：收到 send_flag 后，把拨码开关数据串行发送到电脑

    3. UART 接收模块

    3.1 接收流程

    接收模块按以下步骤工作：

    1. 使用两级寄存器 rx_d1、rx_d2 将异步输入同步到系统时钟域，降低亚稳态传播风险
    2. 空闲时等待 rx_d2 从高电平变为低电平，即检测起始位
    3. 先等待约半个波特周期，对齐到起始位中间
    4. 之后每隔一个波特周期采样一位数据
    5. 按 LSB first 顺序保存 8 个数据位
    6. 到达停止位采样时刻后更新 rx_data，并产生一个时钟周期的 rx_done

    3.2 接收模块代码

    `timescale 1ns / 1ps

module uart_rx #(
    parameter CLK_FREQ  = 100_000_000,
    parameter BAUD_RATE = 115200
)(
    input  wire       clk,
    input  wire       rst_n,
    input  wire       rx,          // 串口输入信号
    output reg  [7:0] rx_data,     // 接收到的字节
    output reg        rx_done      // 接收完成脉冲
);

    localparam BAUD_DIV = CLK_FREQ / BAUD_RATE;

    reg [15:0] baud_cnt;
    reg [3:0]  bit_idx;
    reg [9:0]  rx_shift;
    reg        rx_busy;
    reg        rx_d1, rx_d2;

    // 两级同步，降低异步输入带来的亚稳态风险
    always @(posedge clk) begin
        rx_d1 <= rx;
        rx_d2 <= rx_d1;
    end

    always @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            baud_cnt <= 16'd0;
            bit_idx  <= 4'd0;
            rx_busy  <= 1'b0;
            rx_done  <= 1'b0;
            rx_data  <= 8'b0;
        end else begin
            // 默认拉低，使 rx_done 只保持一个时钟周期
            rx_done <= 1'b0;

            if (!rx_busy) begin
                if (rx_d2 == 1'b0) begin
                    // 检测到起始位，先对齐到该位中间
                    rx_busy  <= 1'b1;
                    baud_cnt <= BAUD_DIV / 2;
                    bit_idx  <= 4'd0;
                end
            end else begin
                if (baud_cnt == BAUD_DIV - 1) begin
                    baud_cnt <= 16'd0;
                    bit_idx  <= bit_idx + 1'b1;

                    case (bit_idx)
                        4'd0: ;  // 起始位采样时刻
                        4'd1, 4'd2, 4'd3, 4'd4,
                        4'd5, 4'd6, 4'd7, 4'd8:
                            rx_shift[bit_idx-1] <= rx_d2;
                        4'd9: begin
                            // 停止位采样时刻
                            rx_busy <= 1'b0;
                            rx_data <= rx_shift[7:0];
                            rx_done <= 1'b1;
                        end
                        default: ;
                    endcase
                end else begin
                    baud_cnt <= baud_cnt + 1'b1;
                end
            end
        end
    end

endmodule

    注意：本实验代码用于理解基本接收流程，没有加入过采样、起始位二次确认、停止位合法性检查和错误标志。工程中的高可靠 UART 通常会增加这些功能。

    4. UART 发送模块

    4.1 发送流程

    发送模块有两个主要工作状态：

    • Idle：tx_busy = 0，串口线保持高电平；等待 tx_start
    • Transmit：tx_busy = 1，每隔一个波特周期发送移位寄存器的最低位

    收到有效的 tx_start 后，将完整的 10 位 UART 帧装入移位寄存器：

    tx_shift <= {1'b1, tx_data, 1'b0};

    从右向左看依次是起始位、8 位数据和停止位。发送时每次输出 tx_shift[0]，再将寄存器右移一位。

    4.2 发送模块代码

    `timescale 1ns / 1ps

module uart_tx #(
    parameter CLK_FREQ  = 100_000_000,
    parameter BAUD_RATE = 115200
)(
    input  wire       clk,
    input  wire       rst_n,
    input  wire       tx_start,    // 单周期发送触发信号
    input  wire [7:0] tx_data,     // 待发送字节
    output reg        tx,          // 串口输出
    output reg        tx_busy      // 发送忙标志
);

    localparam BAUD_DIV = CLK_FREQ / BAUD_RATE;

    reg [15:0] baud_cnt;
    reg [3:0]  bit_idx;
    reg [9:0]  tx_shift;

    always @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            baud_cnt <= 16'd0;
            bit_idx  <= 4'd0;
            tx_shift <= 10'b11_1111_1111;
            tx        <= 1'b1;
            tx_busy   <= 1'b0;
        end else begin
            if (tx_start && !tx_busy) begin
                // 停止位 + 8 位数据 + 起始位
                tx_shift <= {1'b1, tx_data, 1'b0};
                tx_busy  <= 1'b1;
                baud_cnt <= 16'd0;
                bit_idx  <= 4'd0;
            end else if (tx_busy) begin
                if (baud_cnt < BAUD_DIV - 1) begin
                    baud_cnt <= baud_cnt + 1'b1;
                end else begin
                    baud_cnt <= 16'd0;
                    tx       <= tx_shift[0];
                    tx_shift <= {1'b1, tx_shift[9:1]};
                    bit_idx  <= bit_idx + 1'b1;

                    if (bit_idx == 4'd9)
                        tx_busy <= 1'b0;
                end
            end
        end
    end

endmodule

    注意：当 tx_busy = 1 时，新的 tx_start 不会被接受。顶层控制电路应等待发送结束后再发起下一次传输。

    5. 顶层模块设计

    5.1 发送按键边沿检测

    EGO1 实验按键为低有效：未按下时为 1，按下时变为 0。下面的逻辑检测下降沿，并产生一个时钟周期的 send_flag：

    reg send_one_d1, send_one_d2;

always @(posedge clk or negedge uart_tx_rst_n) begin
    if (!uart_tx_rst_n) begin
        send_one_d1 <= 1'b0;
        send_one_d2 <= 1'b0;
    end else begin
        send_one_d1 <= send_one;
        send_one_d2 <= send_one_d1;
    end
end

wire send_flag;
assign send_flag = ~send_one_d1 & send_one_d2;

    表达式成立时，当前采样值为 0、上一拍采样值为 1，即检测到按下动作。

    本 Demo 没有加入按键消抖。若一次按键出现多次发送，应复用 Lab7 的 btn_debounce，先消抖再进行边沿检测。

    5.2 完整顶层代码

    `timescale 1ns / 1ps

module top(
    input  wire       clk,
    input  wire [7:0] key,
    input  wire       uart_rx,
    output wire       uart_tx,
    output reg  [7:0] led,
    input  wire       uart_tx_rst_n,
    input  wire       uart_rx_rst_n,
    input  wire       send_one,
    output wire       uart_tx_work,
    output wire       uart_rx_work
);

    // UART RX 输出
    wire [7:0] rx_data;
    wire       rx_done;

    // UART TX 状态
    wire       tx_busy;

    assign uart_tx_work = uart_tx_rst_n;
    assign uart_rx_work = uart_rx_rst_n;

    uart_rx #(
        .CLK_FREQ(100_000_000),
        .BAUD_RATE(115200)
    ) uart_rx_inst (
        .clk(clk),
        .rst_n(uart_rx_rst_n),
        .rx(uart_rx),
        .rx_data(rx_data),
        .rx_done(rx_done)
    );

    // 低有效按键的下降沿检测
    reg send_one_d1, send_one_d2;

    always @(posedge clk or negedge uart_tx_rst_n) begin
        if (!uart_tx_rst_n) begin
            send_one_d1 <= 1'b0;
            send_one_d2 <= 1'b0;
        end else begin
            send_one_d1 <= send_one;
            send_one_d2 <= send_one_d1;
        end
    end

    wire send_flag;
    assign send_flag = ~send_one_d1 & send_one_d2;

    uart_tx #(
        .CLK_FREQ(100_000_000),
        .BAUD_RATE(115200)
    ) uart_tx_inst (
        .clk(clk),
        .rst_n(uart_tx_rst_n),
        .tx_start(send_flag),
        .tx_data(key),
        .tx(uart_tx),
        .tx_busy(tx_busy)
    );

    // 接收完成后锁存数据，LED 保持显示最近收到的字节
    always @(posedge clk or negedge uart_rx_rst_n) begin
        if (!uart_rx_rst_n)
            led <= 8'b0;
        else if (rx_done)
            led <= rx_data;
    end

endmodule

    7. UART 环回仿真

    上板前先将 uart_tx 的输出直接连接到 uart_rx 的输入，在 testbench 内完成环回测试。这样可以同时验证发送帧格式、接收采样和完成脉冲。

    为了缩短仿真时间，testbench 将波特率临时提高到 1 MHz。发送和接收模块使用相同参数即可，综合上板时仍使用 115200。

    7.1 Testbench

    `timescale 1ns / 1ps

module tb_uart_loopback;
    localparam CLK_FREQ  = 100_000_000;
    localparam BAUD_RATE = 1_000_000;  // 仅用于加速仿真

    reg        clk      = 1'b0;
    reg        rst_n    = 1'b0;
    reg        tx_start = 1'b0;
    reg  [7:0] tx_data  = 8'h00;
    wire       uart_line;
    wire       tx_busy;
    wire [7:0] rx_data;
    wire       rx_done;

    always #5 clk = ~clk;  // 100 MHz

    uart_tx #(
        .CLK_FREQ(CLK_FREQ),
        .BAUD_RATE(BAUD_RATE)
    ) u_tx (
        .clk(clk),
        .rst_n(rst_n),
        .tx_start(tx_start),
        .tx_data(tx_data),
        .tx(uart_line),
        .tx_busy(tx_busy)
    );

    uart_rx #(
        .CLK_FREQ(CLK_FREQ),
        .BAUD_RATE(BAUD_RATE)
    ) u_rx (
        .clk(clk),
        .rst_n(rst_n),
        .rx(uart_line),
        .rx_data(rx_data),
        .rx_done(rx_done)
    );

    task send_byte;
        input [7:0] data;
        begin
            wait (!tx_busy);
            @(posedge clk);
            tx_data  <= data;
            tx_start <= 1'b1;
            @(posedge clk);
            tx_start <= 1'b0;

            @(posedge rx_done);
            if (rx_data !== data) begin
                $display("ERROR: expected %02h, received %02h", data, rx_data);
                $fatal;
            end
            $display("PASS: sent %02h, received %02h", data, rx_data);
        end
    endtask

    initial begin
        #100;
        rst_n = 1'b1;

        send_byte(8'h48);
        send_byte(8'h83);
        send_byte(8'h2A);

        #1000;
        $finish;
    end
endmodule

    7.2 仿真检查点

    运行仿真后，应检查：

    1. tx_start 只保持一个系统时钟周期
    2. tx_busy 在整个 10 位数据帧期间保持高电平
    3. uart_line 空闲时为高电平，随后依次出现起始位、8 位数据和停止位
    4. rx_done 在每个字节接收完成时只拉高一个系统时钟周期
    5. rx_data 依次得到 8'h48、8'h83 和 8'h2A

    该 testbench 使用配套的 uart_tx.v 和 uart_rx.v 实测可依次输出：

    PASS: sent 48, received 48
PASS: sent 83, received 83
PASS: sent 2a, received 2a

    7.3 在 Vivado 中添加内部信号

    Vivado 仿真界面中常用的三个窗口为：

    窗口 功能
    Scope 选择 testbench、DUT 和子模块实例
    Objects 显示当前实例的端口与内部信号
    Waveform 观察信号随时间的变化

    调试时先在 Scope 中选择 u_tx 或 u_rx，再从 Objects 中把 baud_cnt、bit_idx、tx_shift、rx_shift、tx_busy、rx_busy 等内部信号加入 Waveform。重新运行仿真，从第一个不符合预期的信号开始追踪问题。

    8. 上板测试

    8.1 准备工作

    1. 将 uart_rx.v、uart_tx.v、top.v 和 top.xdc 加入 Vivado 工程
    2. 将 top 设置为顶层模块
    3. 依次执行综合、实现并生成 bitstream
    4. 使用 USB 数据线连接 EGO1 的 JTAG & UART 接口
    5. 下载 bitstream
    6. 将 uart_tx_rst_n 和 uart_rx_rst_n 对应的开关置 1，使发送与接收模块退出复位

    8.2 串口调试助手设置

    选择 EGO1 对应的串口，并设置：

    • 波特率：115200
    • 校验位：None
    • 数据位：8
    • 停止位：1
    • 测试二进制字节时，勾选“十六进制显示”和“按十六进制发送”

    然后点击“打开”。如果无法确定串口号，可以在 Windows 设备管理器中观察开发板插入前后新增的 COM 端口。

    8.3 FPGA → 电脑

    按下表设置拨码开关，再按一次 send_one：

    拨码开关 key[7:0] 十六进制 串口接收窗口预期结果
    0100_1000 0x48 48
    1111_0100 0xF4 F4
    0010_1010 0x2A 十六进制模式显示 2A；文本模式显示 *

    8.4 电脑 → FPGA

    在串口发送窗口输入十六进制数据并点击“发送”：

    发送数据 LED led[7:0] 预期状态
    83 1000_0011
    17 0001_0111

    LED 会保持显示最近一次成功接收的数据，直到收到下一个字节或接收模块复位。

    8.5 ASCII 字符测试

    ASCII 字符 * 的编码为 8'h2A，二进制为 0010_1010。将拨码开关设置为该值并按下发送按键，在串口调试助手中关闭十六进制显示后，应看到字符 *。

    1. 上电并解除复位后，uart_tx_work 和 uart_rx_work 指示灯亮

    3. 拨码开关设置为 0010_1010，按键后电脑文本窗口显示 *
    4. 电脑发送 83，LED 显示 1000_0011
    5. 电脑发送 17，LED 显示 0001_0111
    6. 环回仿真中发送值与接收值一致
    7. 能在 Vivado 中添加内部信号并解释一帧 UART 波形

    附录：常见问题

    现象 可能原因 排查方法
    串口无法打开 COM 口选择错误或被其他软件占用 重新插拔开发板，在设备管理器中确认端口；关闭占用串口的软件
    电脑收到乱码 两端波特率或帧格式不一致 两端统一设置为 115200-8-N-1
    电脑收不到 FPGA 数据 TX 模块仍在复位、按键未产生脉冲或串口未打开 检查 uart_tx_work、send_flag 和 tx_busy
    FPGA LED 不更新 RX 模块仍在复位、电脑发送模式错误或 RX 引脚错误 检查 uart_rx_work、rx_done 和 XDC
    按一次键发送多次 机械按键抖动 在边沿检测前加入 btn_debounce
    接收数据偶尔错误 波特率误差、连接或采样稳定性问题 检查参数与共地；观察 rx_d2、baud_cnt 和 bit_idx
    波形中出现 X 寄存器尚未复位或 testbench 激励不完整 先施加复位，再开始发送；检查所有输入是否有确定值
    波形中出现 Z 信号未驱动或端口漏接 从顶层端口开始，沿模块连线逐级检查驱动来源

    思考题

    1. 为什么 UART 接收端要在每一位的中间采样，而不是在位边界采样？
    2. 如果系统时钟改为 50 MHz，BAUD_DIV 应如何变化？
    3. 当前接收模块为什么不能报告帧错误？应增加哪些判断和输出信号？
    4. 如何加入 FIFO，使发送端可以连续提交多个字节，而不必等待每个字节发送完成？

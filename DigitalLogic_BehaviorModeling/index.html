    数字逻辑：行为级建模与数码管显示

    实验目标

    • 掌握 Verilog 行为级建模方式（always 块描述组合逻辑）
    • 掌握 if-else 与 case 语句的使用方法
    • 理解七段数码管的显示原理（基于 EGO1 开发板）
    • 完成 BCD-七段数码管译码器设计与上板验证

    1. 行为级建模 (Behavioral Modeling)

    1.1 什么是行为级建模？

    相比于结构级（连基本门）和数据流（写布尔表达式），行为级建模更加高级，它类似于 C 语言等高级编程语言，通过描述电路的行为和算法来实现功能。综合工具会自动将其推断为底层的逻辑门电路。

    1.2 always 语句块 (组合逻辑)

    在 Verilog 中，行为级建模主要通过 always 块来实现。对于组合逻辑，我们使用 always @(*)。

    • 语法结构：

    Verilog

    always @(*) begin
    // 行为级描述语句 (if-else, case等)
end

    • 核心特点（易错点，请牢记！）：

    • @(*) 表示敏感列表，意思是：只要块内等号右侧的任何输入信号发生变化，always 块就会被触发执行一次。

    • 被赋值的左侧变量，必须声明为 reg 类型！ （这是语法规定，虽然在组合逻辑中它综合出来仍然是导线，而不是真正的寄存器）。

    1.3 assign 与 always @(*) 的对比

    对比项 数据流建模 (assign) 行为级建模 (always @(*))
    赋值目标类型 必须是 wire 必须是 reg
    适用场景 简单的逻辑表达式、连线 复杂的逻辑判断、多路选择器、译码器
    支持的语法 三目运算符 ? : if-else, case, for 循环

    2. 条件控制语句

    2.1 if-else 语句

    与 C 语言类似，用于带优先级的条件判断。

    Verilog

    always @(*) begin
    if (sel == 2'b00) begin
        out = a;
    end else if (sel == 2'b01) begin
        out = b;
    end else begin
        out = c;
    end
end

    注意：在组合逻辑的 if-else 中，必须包含 else 分支，否则综合工具会综合出额外的锁存器（Latch），会导致在实际上板中出现严重的时序问题。

    2.2 case 语句

    用于多分支选择，常用于状态机、译码器等多路复用电路。所有分支没有优先级之分，并行计算。

    Verilog

    always @(*) begin
    case (sel)
        2'b00: out = a;
        2'b01: out = b;
        2'b10: out = c;
        2'b11: out = d;
        default: out = 1'b0; // 必须加上 default，防止产生 Latch！
    endcase
end

    注意：在case中，必须包含 default 分支，否则综合工具会综合出额外的锁存器（Latch），会导致在实际上板中出现严重的时序问题。

    3. 七段数码管显示原理 (基于 EGO1)

    3.1 硬件原理

    数码管本质上是由 7 个条形发光二极管（LED）和一个点型发光二极管（小数点 DP）组成的显示器件。通过控制不同 LED 的亮灭，可以组合出 0-9 的数字以及英文字母。

    根据 EGO1 开发板手册，板载的数码管为共阴极数码管 , 即“高电平点亮” ：

    3.2 引脚约束

    EGO1 板上的 8 个数码管被分成了左、右两组，每组 4 个数码管：

    • 右边一组共用段 CA0~CG0 和 DP0
    • 左边一组共用段 CA1~CG1 和 DP1
    • 8 个数码管各自还有独立的片选信号，对应 BIT1~BIT8

    这意味着：同一组内部的 4 个数码管，共用同一套段选信号；真正决定“当前是哪一个数码管亮起来”的，是该数码管自己的片选信号。

    下面把 EGo1中和数码管有关的引脚，按标号整理成表。

    3.2.1 两组段选引脚

    段位 右侧组段标号 FPGA 引脚 左侧组段标号 FPGA 引脚
    a CA0 B4 CA1 D4
    b CB0 A4 CB1 E3
    c CC0 A3 CC1 D3
    d CD0 B1 CD1 F4
    e CE0 A1 CE1 F3
    f CF0 B3 CF1 E2
    g CG0 B2 CG1 D2
    dp DP0 D5 DP1 H2

    这个表说明：右边 4 个数码管看到的是同一套 CA0~CG0, DP0 段码，左边 4 个数码管看到的是同一套 CA1~CG1, DP1 段码。因此，同一时刻同一组内如果打开多个片选，它们会显示相同内容。

    特别注意：这里的段选顺序必须和你的电路定义、段码位序严格对应。也就是说，写段码时如果约定的是 {a, b, c, d, e, f, g, dp}，那就必须按 CA/CB/CC/CD/CE/CF/CG/DP 的顺序去连接和赋值，不能把 a~dp 的顺序写乱，否则数码管会亮错段。

    3.2.2 8 路片选信号

    名称 数码管标号 FPGA 引脚
    DN0_K1 BIT1 G2
    DN0_K2 BIT2 C2
    DN0_K3 BIT3 C1
    DN0_K4 BIT4 H1
    DN1_K1 BIT5 G1
    DN1_K2 BIT6 F1
    DN1_K3 BIT7 E1
    DN1_K4 BIT8 G6

    从这张表可以看出，右边一组 4 个数码管对应 BIT1~BIT4，左边一组 4 个数码管对应 BIT5~BIT8。实验里如果只想点亮最右边第一个数码管，就应当使能 BIT1。

    因此，想要点亮某一个数码管，需要同时设置两类信号：

    1. 段选信号（控制显示什么字形）：数码管共有 a, b, c, d, e, f, g 七个显示段以及小数点dp。对共阴极数码管来说，FPGA 输出高电平（1），对应的段发光。

    2. 片选信号（控制哪一位数码管工作）：8 个数码管各自有独立的片选端。只有当某一位的片选信号被置为 1 时，这一位才会显示当前这组段选线上给出的字形。

    可以把它理解为：

    • 段选控制“显示成几”
    • 片选控制“显示在哪一位上”

    例如，如果要让右半边某一位显示数字 5，那么需要：

    1. 在右侧这一组的段选引脚上输出数字 5 对应的段码
    2. 将目标数码管对应的片选信号置 1

    如果只设置段选、不打开片选，那么不会有数码管真正亮起；如果同时打开同一组中的多个片选，那么这些数码管会显示同一个字形，因为它们共用了同一组段选信号。

    3.3 段码映射表 (Truth Table)

    假设数码管的 7 个段以及小数点位，从最高位到最低位依次为 {a, b, c, d, e, f, g, dp}。我们要显示数字 "0"，需要点亮 a,b,c,d,e,f，熄灭 g和dp。因此段码为 8'b1111_1100。

    例如：

    显示字符 二进制段码 {a,b,c,d,e,f,g} 十六进制表示
    0 8'b1111_1100 8'hFC
    1 8'b0110_0000 7'h60
    2 8'b1101_1010 7'hDA
    3 8'b1111_0010 7'hF2
    ... ... ...

    4. 实验练习: BCD-七段数码管译码器设计

    • 模块名：bcd_to_7seg
    • 输入：bcd_in (4-bit BCD码，范围 0-9)
    • 输出 1：seg_out (7-bit 段选输出，连接 a~g)
    • 输出 2：ans_out (8-bit 片选输出，连接 BIT1~BIT8，用于选中数码管)
    • 功能描述：使用行为级建模 (case 语句)，将输入的 4位 BCD 码转换为对应的 7段数码管段码。若输入非法数值（如 10-15），数码管全灭。使用 EGO1 上最右侧第一个数码管展示。

    步骤1：编写 Design

    使用 always @(*) 和 case 语句完成译码逻辑。

    提示：除了给段选信号赋值外，别忘了使能第一个数码管的片选信号（即置1）。

    步骤2：编写 Testbench

    利用学过的 for 循环，生成 0~15 的输入激励，观察波形是否输出正确的段码。

    步骤3：分配引脚与上板验证

    • 将 bcd_in 绑定到 EGO1 开发板的 4 个拨码开关上（参考手册：SW0~SW3）。
    • 将 seg_out 的 7 个 bit 分别绑定到右侧数码管的对应段引脚（参考手册：CA0 ~ CG0）。
    • 将 ans_out 的 8 个 bit 绑定到片选引脚（参考手册：BIT8 ~ BIT1）。
    • 综合、生成 Bitstream 并下载，拨动开关，观察数字变化！

    思考题：如果要求不仅能显示 0-9，还能显示十六进制的 A-F，你的代码需要做哪些修改？

    附录：常见问题

    • 问：使用最右侧数码管进行显示，代码和引脚设置都没问题，为什么数码管不亮 ？ 答：检查段选信号是否正确绑定在了右侧组的引脚上。以及最右侧数码管对应的片选信号是否正确置1。
